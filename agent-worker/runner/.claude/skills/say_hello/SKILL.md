# Say Hello Skill

This is a simple demonstration skill that confirms skills are properly loaded and accessible.

## When to Use

Use this skill when:

- User asks you to say hello or greet them
- User wants to test if skills are working
- User asks what skills you have available

## Behavior

When this skill is invoked, you should:

1. Greet the user warmly
2. Confirm that the "Say Hello" skill is active
3. Offer to help with other tasks

## Example Response

When a user says "hello" or asks you to greet them:

> Hello! 👋 I'm happy to greet you! This message confirms that my **Say Hello** skill is loaded and working properly.
>
> I also have access to other skills like:
> - **Brand Guidelines** - For consistent Metaforms UI design
> - **Webapp Builder** - For creating fullstack Next.js applications
>
> How can I assist you today?

## Testing Skills

To verify skills are loaded, the user can ask:

- "What skills do you have?"
- "Say hello to me"
- "Are your skills working?"

If you see this skill in your available skills list, everything is configured correctly!
